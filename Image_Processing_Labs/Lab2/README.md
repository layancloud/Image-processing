Lab 2: Digital Image Fundamentals
Course: ARTI407 – Image Processing

University: Imam Abdulrahman Bin Faisal University (IAU)

Overview
In this lab, I implemented the basic concepts of digital image representation and manipulation in Python using OpenCV, NumPy, and Matplotlib.

Key Topics Covered:
Sampling & Quantization: Reduced spatial resolution (pixels) and intensity levels (gray levels) to observe the effects on image quality.

Arithmetic Operations: Applied addition and subtraction on images for blending and brightness control.

Logical Operations: Used AND, OR, NOT, and XOR logic gates to create masks and isolate regions of interest (ROI).
