# Lab 4: Image Intensity Rescaling & Histogram Matching

This lab covers fundamental histogram processing and intensity transformation techniques using Python and `scikit-image`.

## Tasks Covered
1. Intensity Rescaling: Rescaling image intensity values based on the 3rd and 80th percentiles using `exposure.rescale_intensity`.
2. Histogram Equalization: Enhancing image contrast by flattening its histogram using `exposure.equalize_hist`.
3. Histogram Matching: Matching the intensity distribution of a source image (`chelsea`) to a reference image (`rocket`) using `exposure.match_histograms`.
