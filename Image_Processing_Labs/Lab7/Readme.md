# Lab 7 – Otsu's Thresholding

## Description
This program applies Otsu's thresholding to an image using OpenCV. It shows the original image, its histogram, and the thresholded image.

## Libraries
- OpenCV (cv2)
- NumPy
- Matplotlib
- scikit-image

## How to Run
1. Open the notebook `Lab7_Image_Segmentation_Feature_Extraction.ipynb`.
2. Run the setup cell to import the libraries.
3. Run the Q1 cell.

## Output
- Original image
- Histogram of the image
- Image after Otsu's thresholding
